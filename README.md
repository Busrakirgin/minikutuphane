# 📚 Mini Kütüphane Otomasyonu

Python ve SQL Server kullanarak geliştirilmiş, kitap ve üye yönetimini kolaylaştıran mini bir kütüphane takip otomasyon sistemidir.

## 🚀 Özellikler
- Kitap ekleme, silme ve listeleme
- SQL Server (SSMS) veritabanı entegrasyonu
- Kullanıcı dostu arayüz

## 💻 Kullanılan Teknolojiler
- **Programlama Dili:** Python
- **Veritabanı:** SQL Server (SSMS)
- **Arayüz:** Tkinter
